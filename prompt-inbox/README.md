# Prompt Inbox

Keep raw visual prompts here before they become public Image Skillbook recipes.

Use either intake style:

- paste several entries into `INBOX.md`; or
- create one Markdown file per prompt in this directory.

An intake review must scan every Markdown file here except `README.md` and
`STATUS.md`. It must inventory the files before deduplicating, preserve source URLs and
author notes, and never remove an entry until its specific recipe has been reviewed.

This directory is ignored by Git except for this guide. Raw prompts may therefore be
incomplete, duplicated, unattributed, or copied from a social post without becoming
public repository content. Add the source, author, model, example, or reuse terms when
known.

Public recipe wording belongs in `references/recipes/`; each independently installable
style belongs in `skills/`. Unknown third-party rights require an independently written
abstraction rather than copying the raw prompt.

When a treatment is ready to become public, follow the repository's
[`CONTRIBUTING.md`](../CONTRIBUTING.md) workflow. Prompt intake is a maintainer process rather
than a responsibility of the public style-selection router.
